# YouTube Personal Downloader — Windows + Chrome

## เวอร์ชัน 1.5 — ปุ่มดาวน์โหลด Shorts และข้อมูลเวอร์ชัน

รองรับแถบปุ่ม Shorts แบบใหม่และแบบเก่า แทรกปุ่ม Download หลังปุ่ม Share พร้อมติดตามคลิปที่เปิดอยู่เมื่อเลื่อนเปลี่ยนคลิป
แสดงเวอร์ชัน วันที่เผยแพร่ วันที่ติดตั้ง/อัปเดตในเครื่อง และเวลาตรวจอัปเดตล่าสุดใน popup ของ Chrome
ต้องใช้ Chrome 114 ขึ้นไป เมนูดาวน์โหลดแสดงเหนือชั้นวิดีโอเพื่อไม่ถูกตัดด้วยกรอบ Shorts
อัปเดตจากรุ่น 1.4 ขึ้นไปผ่านปุ่มตรวจอัปเดต แล้วรีเฟรชหน้า YouTube ได้เลย


## เวอร์ชัน 1.4 — ไม่ต้องล็อกอิน GitHub

อัปเดตจาก public GitHub Releases โดยตรง ไม่ต้องมีบัญชี GitHub ไม่ต้องติดตั้ง GitHub CLI และไม่ต้องเปิด CONNECT-GITHUB.cmd
ผู้ใช้เดิม: แตกชุด 1.4 รัน UPDATE.cmd แล้วกด Reload ส่วนขยายหนึ่งครั้ง เพื่อเปลี่ยนระบบอัปเดตเก่า
เครื่องใหม่: รัน INSTALL.cmd แล้วโหลดโฟลเดอร์ extension ใน chrome://extensions ผ่าน Developer mode
จากนั้นตรวจอัปเดตทุก 6 ชั่วโมงขณะเปิด Chrome หรือกดปุ่มตรวจอัปเดตใน popup
ข้อความเกี่ยวกับ private repo และการลงชื่อเข้าใช้ในหัวข้อเวอร์ชันเก่าด้านล่างใช้กับเวอร์ชันเก่าเท่านั้น


## เวอร์ชัน 1.3 — อัปเดตอัตโนมัติผ่าน private GitHub

สำหรับผู้ใช้เดิม: รัน UPDATE.cmd จากชุด 1.3 และกด Reload ส่วนขยายหนึ่งครั้ง เพื่อเพิ่มระบบอัปเดตนี้
จากนั้นเปิด CONNECT-GITHUB.cmd หนึ่งครั้ง ลงชื่อเข้าใช้ GitHub ด้วยบัญชีของตัวเองที่มีสิทธิ์อ่าน adulycode/youtube-personal-downloader
โปรแกรมจะติดตั้ง GitHub CLI หากยังไม่มี และให้คุณทำขั้นตอนลงชื่อเข้าใช้ผ่านเบราว์เซอร์เอง
ห้ามแชร์ token หรือบัญชีเจ้าของ repo ให้เพื่อน เพื่อนแต่ละคนต้องได้รับสิทธิ์ repo และเชื่อมบัญชีของตนเอง

หลังเชื่อมแล้ว ส่วนขยายจะตรวจ stable Release ทุก 6 ชั่วโมงขณะที่เปิด Chrome หรือกด “ตรวจอัปเดตจาก GitHub” ใน popup ได้ทันที
เมื่อมีเวอร์ชันใหม่ โปรแกรมช่วยจะตรวจ SHA-256, รายชื่อไฟล์, เวอร์ชันและ ID ก่อนแทนที่ไฟล์ ส่วนขยายจะ reload ตัวเอง
ต้องรีเฟรชหน้า YouTube ที่เปิดอยู่ เพื่อให้ใช้ปุ่มของเวอร์ชันใหม่
ไม่ต้องแตก ZIP หรือรัน INSTALL.cmd ทุกครั้งหลังตั้งค่าครบแล้ว
หากไม่มีสิทธิ์ repo / ยังไม่ลงชื่อเข้าใช้ / ไม่มีอินเทอร์เน็ต จะไม่อัปเดต และดูสถานะได้ใน popup
การอัปเดตอัตโนมัติไม่เปลี่ยน Python environment หรือ Registry หากอนาคตเปลี่ยน dependency หรือโครงสร้างติดตั้ง อาจต้องซ่อมการติดตั้งแยกต่างหาก

## ปุ่มดาวน์โหลดแบบไอคอน

ปุ่มลูกศรลงวงกลมอยู่ในแถวปุ่มใต้คลิป กดเพื่อเปิดเมนู MP4/MP3 แทนแถบขนาดใหญ่

## เวอร์ชัน 1.1 — ปุ่มบนหน้า YouTube และอัปเดตโดยไม่ติดตั้งใหม่

มีปุ่ม Download บริเวณใต้คลิป YouTube พร้อมตัวเลือก MP4/MP3 และความละเอียด
หน้าอื่นหรือหน้า YouTube ที่ไม่ใช่คลิปจะกดดาวน์โหลดใน popup ไม่ได้
ลิงก์ใน popup อ่านจากคลิปที่เปิดอยู่ ไม่ต้องวางลิงก์เอง

หากติดตั้งเวอร์ชันเดิมแล้ว: แตก ZIP ใหม่นี้ แล้วรัน **UPDATE.cmd**
ตัวอัปเดตหาตำแหน่งติดตั้งจาก Registry และคัดลอกไฟล์ทับลงโฟลเดอร์เดิม โดยเก็บ ID และ Python environment เดิม
รอให้งานดาวน์โหลดจบก่อนอัปเดต แล้วไป chrome://extensions กดปุ่มลูกศรวน **Reload** บนการ์ด YouTube Personal Downloader และรีเฟรชหน้า YouTube
หาก Chrome ขออนุญาตเข้าถึง YouTube เพิ่มเติม ให้ยอมรับเพื่อแสดงปุ่มบนหน้าเว็บ
ไม่ต้องกด Load unpacked ใหม่ และไม่ต้องรัน INSTALL.cmd ซ้ำ
เป็นการอัปเดตจากไฟล์ ZIP ที่รับมาเอง ยังไม่มีระบบดึงเวอร์ชันใหม่จากอินเทอร์เน็ตอัตโนมัติ
หากคุณลบส่วนขยายหรือยังไม่ได้โหลดเข้า Chrome มาก่อน ให้ทำขั้นตอนติดตั้งครั้งแรก

ส่วนขยายส่วนตัว เลือกดาวน์โหลดวิดีโอ MP4 หรือเสียง MP3 จากลิงก์ YouTube ทีละคลิป
รองรับ watch, Shorts, live URL ที่เป็นคลิป และ youtu.be ไม่ดาวน์โหลดทั้ง playlist
ใช้กับเนื้อหาที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ดาวน์โหลด

## ติดตั้งแบบเร็ว (เวอร์ชันกำหนด ID อัตโนมัติ)

1. แตก ZIP เก็บในโฟลเดอร์ถาวร แล้วดับเบิลคลิก INSTALL.cmd
2. ตัวติดตั้งอ่าน Extension ID อัตโนมัติ และติดตั้งโปรแกรมที่ขาดผ่าน winget (อาจมีหน้าต่างขออนุญาตจาก Windows)
3. เปิด Chrome ไปที่ chrome://extensions เปิด Developer mode แล้วกด Load unpacked เลือกโฟลเดอร์ extension
4. ปิดแล้วเปิด Chrome ใหม่ จากนั้นใช้งานได้ตามหัวข้อดาวน์โหลด

ไม่ต้องคัดลอกหรือกรอก Extension ID เพราะ manifest มี public key กำหนด ID ไว้แล้ว
หากไม่มี winget หรือการติดตั้ง dependency ล้มเหลว ให้ติดตั้งด้วยตนเองตามหัวข้อถัดไป แล้วรัน INSTALL.cmd ใหม่

## 1. เตรียมโปรแกรมที่ต้องใช้ (กรณีติดตั้งอัตโนมัติไม่สำเร็จ)

ต้องมี Python 3.10 ขึ้นไป, FFmpeg (รวม ffprobe) และ Deno
ตัวติดตั้งจะติดตั้ง yt-dlp ใน Python environment แยกเฉพาะส่วนขยายนี้
ไม่รวม executable ของบุคคลที่สามมากับชุดไฟล์นี้

ถ้าเครื่องมี winget ให้เปิด PowerShell แล้วรันทีละคำสั่ง:

```powershell
winget install --id Python.Python.3.12 -e
winget install --id Gyan.FFmpeg -e
winget install --id DenoLand.Deno -e
```

หากมีโปรแกรมนั้นอยู่แล้ว ข้ามคำสั่งของโปรแกรมนั้นได้
หลังติดตั้งให้ปิดแล้วเปิด PowerShell และ Chrome ใหม่ เพื่อให้มองเห็น PATH ใหม่
ตรวจสอบด้วย `python --version`, `ffmpeg -version`, `ffprobe -version`, `deno --version`
หาก winget ใช้ไม่ได้ ดูลิงก์จากผู้พัฒนาด้านล่าง
อีกทางเลือก: วาง ffmpeg.exe, ffprobe.exe และ deno.exe ในโฟลเดอร์ native/tools

## 2. โหลดส่วนขยาย

1. แตก ZIP เก็บไว้ในที่ถาวร เช่น Documents\YouTube-Downloader (ไม่โหลดจากใน ZIP)
2. เปิด Chrome ไปที่ `chrome://extensions`
3. เปิด Developer mode ที่มุมขวาบน
4. กด Load unpacked แล้วเลือกโฟลเดอร์ **extension** ในชุดไฟล์นี้
5. ไม่ต้องคัดลอก ID ตัวติดตั้งรู้ ID ล่วงหน้าแล้ว

## 3. เชื่อมต่อโปรแกรมช่วย

1. ดับเบิลคลิก **INSTALL.cmd**
2. ตัวติดตั้งอ่าน Extension ID ให้อัตโนมัติ ไม่ต้องกรอกเอง
3. รอจนติดตั้ง yt-dlp และขึ้น Native host registered
4. ปิดแล้วเปิด Chrome ใหม่

ไม่ต้อง Run as administrator สคริปต์เขียน Registry เฉพาะบัญชี Windows ปัจจุบัน
ต้องต่ออินเทอร์เน็ตเพื่อติดตั้ง dependency ครั้งแรก
อย่าย้ายโฟลเดอร์หลังติดตั้ง ถ้าย้ายให้รัน INSTALL.cmd ใหม่
อย่าลบหรือเปลี่ยนค่า key ใน extension/manifest.json เพราะใช้กำหนด ID ถาวร

## 4. ดาวน์โหลด

1. เปิดหน้าคลิป YouTube แล้วคลิกส่วนขยายจากเมนูรูปจิ๊กซอว์ของ Chrome (ปักหมุดได้)
2. ตรวจสอบลิงก์ หรือวางลิงก์คลิปที่ต้องการเอง
3. เลือก MP4 และความละเอียดสูงสุด หรือ MP3 ที่ 192 kbps
4. กดดาวน์โหลด ดูสถานะในหน้าต่างส่วนขยาย เปิดกลับมาดูได้
5. ไฟล์บันทึกที่ `%USERPROFILE%\Downloads\YouTube Personal`

MP4 ใช้แทร็ก MP4/M4A ที่มีอยู่จริงในคลิป เลือกความละเอียดไม่เกินค่าที่ตั้งไว้
หากไม่มีแทร็กที่รองรับ จะแจ้งข้อผิดพลาดแทนการอ้างว่าดาวน์โหลดได้
MP3 192 kbps เป็นอัตราบิตไฟล์ที่แปลง ไม่ได้ทำให้คุณภาพต้นฉบับเพิ่มขึ้น
โปรแกรมไม่เขียนทับไฟล์เดิม ปิด popup ได้ระหว่างทำงาน แต่ต้องเปิด Chrome ไว้
รองรับครั้งละหนึ่งงาน ยกเลิกแล้วไฟล์ชั่วคราว .part อาจคงอยู่และลบเองได้
ไฟล์จะเก็บใน Downloads ใต้โฟลเดอร์ผู้ใช้ แม้คุณจะเปลี่ยนตำแหน่ง Downloads ของ Windows ไว้ที่อื่น

## ปัญหาที่อาจพบ

- เชื่อมต่อโปรแกรมช่วยไม่ได้: ตรวจสอบ ID แล้วรัน INSTALL.cmd ใหม่ และตรวจว่าโฟลเดอร์ไม่ได้ถูกย้าย
- Missing ffmpeg/ffprobe/deno: ติดตั้งให้ครบแล้วเปิด Chrome ใหม่ หรือวาง executable ใน native/tools
- YouTube ขอให้ลงชื่อเข้าใช้ / จำกัดสิทธิ์ / คลิปส่วนตัว / สมาชิก / DRM: เวอร์ชันนี้ไม่ดึง cookie หรือข้ามข้อจำกัดเหล่านั้น
- YouTube เปลี่ยนระบบ: รัน INSTALL.cmd อีกครั้งเพื่ออัปเดต yt-dlp แล้วลองใหม่
- คลิป live ที่กำลังออกอากาศ: งานอาจทำต่อเนื่องจนรายการจบ กดยกเลิกได้ (ยังไม่ได้ทดสอบ live)
- หาก Python มีหลายเวอร์ชัน ให้ตรวจว่า `python --version` ใช้งานได้ก่อนรันตัวติดตั้ง

## ถอนการติดตั้ง

ลบส่วนขยายที่ chrome://extensions แล้วเปิด PowerShell ในโฟลเดอร์ชุดไฟล์และรัน:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native\uninstall.ps1
```

จากนั้นลบโฟลเดอร์ชุดไฟล์ได้ ไฟล์ที่ดาวน์โหลดไว้จะยังอยู่

## ความเป็นส่วนตัวและโครงสร้าง

ส่วนขยายอ่าน URL แท็บปัจจุบันเมื่อเปิด popup และส่งลิงก์ที่เลือกไปยังโปรแกรมบนเครื่องผ่าน Chrome Native Messaging
ไม่มี analytics ไม่มีเซิร์ฟเวอร์ของส่วนขยาย และไม่อ่าน cookie ของ Chrome
yt-dlp ติดต่อ YouTube และเซิร์ฟเวอร์สื่อเพื่อดาวน์โหลด
สิทธิ์: activeTab, nativeMessaging, storage
โปรแกรมช่วยยอมรับเฉพาะลิงก์ HTTPS ของคลิป YouTube และกำหนด allowed_origins เป็น ID ของคุณ
คำสั่งดาวน์โหลดเรียกแบบ argument array ไม่ประกอบ URL เป็น shell command
