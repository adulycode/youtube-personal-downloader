# YouTube Personal Downloader 1.6.1 — Windows 10/11 64-bit

## ส่งให้ผู้ใช้ใหม่

ส่งไฟล์ YouTube-Downloader-Setup.exe ไฟล์เดียว เปิดได้เลย ไม่ต้องแตก ZIP
ตัวติดตั้งรวม Python, yt-dlp, FFmpeg, ffprobe และ Deno ไว้แล้ว ไม่พึ่ง Python ของเครื่อง ไม่ต้องติดตั้ง winget หรือเข้าสู่ระบบ GitHub
ตัวติดตั้งไม่ต้องใช้สิทธิ์ Administrator และไม่เปลี่ยน PATH ของเครื่อง
ติดตั้งใหม่ที่ %LOCALAPPDATA%\YouTubePersonalDownloader หรือใช้ตำแหน่งเดิมถ้าพบการติดตั้งเดิม

## ขั้นตอนที่ Chrome ต้องให้ผู้ใช้กดเองหนึ่งครั้ง

เมื่อตัวติดตั้งสำเร็จ จะเปิดหน้า chrome://extensions และโฟลเดอร์ extension พร้อมคัดลอกตำแหน่งโฟลเดอร์ให้
1. เปิด Developer mode ที่มุมขวาบน
2. กด Load unpacked
3. วางตำแหน่งที่คัดลอกไว้ด้วย Ctrl+V แล้วเลือกโฟลเดอร์นั้น
จากนั้นเปิด YouTube หรือรีเฟรชหน้าเดิม ไอคอนดาวน์โหลดจะปรากฏ
Chrome ไม่อนุญาตให้ไฟล์ติดตั้งเพิ่มส่วนขยายส่วนตัวแบบเงียบในเครื่องทั่วไป
หากเคยโหลดส่วนขยายไว้แล้ว ให้กด Reload ที่การ์ดเดิมแทนการโหลดใหม่

## เครื่องเดิมที่มีปัญหา Python

เปิด Setup.exe รุ่นนี้ได้เลย ตัวติดตั้งจะเตรียม Python ของตัวเองและเชื่อมโปรแกรมช่วยใหม่
ถ้าพบโฟลเดอร์เดิมที่มี ID ตรงกัน จะใช้โฟลเดอร์นั้นต่อ จึงไม่ต้องเปลี่ยน ID

## ทางเลือก ZIP

ชุด YouTube-Downloader.zip เหมาะกับผู้ใช้ที่ต้องการไฟล์ต้นฉบับหรืออัปเดตด้วย UPDATE.cmd
INSTALL.cmd รุ่นนี้ดาวน์โหลด runtime ที่จำเป็นให้อัตโนมัติหากไม่ได้มากับชุดไฟล์ ต้องใช้อินเทอร์เน็ต
ไฟล์ Setup.exe รวม runtime มาครบ จึงติดตั้งโปรแกรมช่วยแบบ offline ได้

## ใช้งานและอัปเดต

รองรับคลิปปกติและ YouTube Shorts เลือก MP4 สูงสุด 720p/1080p/4K หรือเสียง MP3 192 kbps
ดาวน์โหลดครั้งละคลิป บันทึกที่ %USERPROFILE%\Downloads\YouTube Personal
กดไอคอนใกล้ Share เพื่อเลือกไฟล์ ใช้กับเนื้อหาที่คุณมีสิทธิ์ดาวน์โหลด
อัปเดตโค้ดจาก public GitHub Releases ทุก 6 ชั่วโมงขณะเปิด Chrome หรือกดตรวจอัปเดตใน popup
ดูเวอร์ชัน วันที่เผยแพร่ และเวลาตรวจล่าสุดได้ใน popup หลังอัปเดตให้รีเฟรชหน้า YouTube
การอัปเดตโค้ดไม่เปลี่ยน binary dependency อัตโนมัติ หากต้องอัปเดตโปรแกรมเหล่านั้นให้เปิด Setup รุ่นใหม่

## ปัญหาและข้อจำกัด

หากองค์กรปิด Developer mode หรือห้ามเปิดโปรแกรมนี้ ต้องให้ผู้ดูแลเครื่องจัดการ
ไฟล์ Setup ยังไม่ได้เซ็นรับรองผู้เผยแพร่ Windows อาจแสดงคำเตือน ไม่สามารถรับประกันว่าจะผ่านนโยบายทุกเครื่อง
หากล็อกไฟล์อยู่ระหว่างติดตั้ง ให้ปิด Chrome และรัน Setup ใหม่
ไม่มีการดึง cookie หรือข้ามข้อจำกัดคลิปส่วนตัว สมาชิก หรือ DRM
ไม่ควรย้ายหรือลบโฟลเดอร์ที่ติดตั้งใน LocalAppData
